# Cherry Wish

Cherry Wish는 벚꽃나무를 누르면 꽃잎이 떨어지고, 그 꽃잎을 잡으면 오늘의 소원 메시지를 확인할 수 있는 단일 페이지 인터랙티브 프로젝트입니다.

직접 보기: [wish.seonghoho.com](https://wish.seonghoho.com)

## 구현한 것

- 벚꽃나무를 중심으로 한 짧고 직관적인 단일 화면 인터랙션
- 나무를 누르면 꽃잎이 흩날리고, 꽃잎을 잡으면 소원 메시지가 열리는 흐름
- 모바일에서도 가볍고 부드럽게 느껴지도록 다듬은 감성적인 봄 시즌 경험
- 다시 하기까지 자연스럽게 이어지는 반복 플레이 구조


## 핵심 경험

나무를 누른다 → 꽃잎이 떨어진다 → 꽃잎을 잡는다 → 소원 메시지를 받는다
